# NOSTRINGS – mock dating PWA

Static files only. No build step. Live at **https://katlegon.github.io/nostrings/**

## Run locally
    python3 -m http.server 8080
Then open http://localhost:8080

## Install on iPhone
Open the live link in **Safari**, then tap Share → **Add to Home Screen**.
It launches full-screen with the NOSTRINGS icon and works offline after the first visit.

## Demo login
Any email + a password of 4+ characters. "Join Now" switches to sign-up (name + 18+ checkbox).
The session is stored in localStorage; Log Out is in the menu (☰ or your name chip).
